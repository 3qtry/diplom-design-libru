# Дипломный проект: Редизайн электронной библиотеки Lib.ru

Современный адаптивный веб-интерфейс для старейшей электронной библиотеки рунета **Lib.ru (Библиотека Максима Мошкова)** с сохранением ретро-эстетики и духа раннего веба 1990-х годов.

## Особенности проекта

- **Архитектура без сборщиков (Vanilla Stack)**: чистый семантический HTML5, CSS3 с CSS Variables и Container Queries, чистый JavaScript (ES6+).
- **Дизайн-система**:
  - Шрифтовая триада: литературная антиква (*Literata*), гротеск (*IBM Plex Sans*) и моноширинный терминальный шрифт (*IBM Plex Mono*).
  - Ретро-брутализм с глубокой проработкой деталей (стилизация под ретро-телевизор с переключением каналов, пейджер, олимпийский пьедестал почёта).
  - Полноценная светлая (газетно-бумажная) и тёмная (терминальная) темы с автопереключением и сохранением выбора.
- **Разделы и страницы**:
  - **Главная**: витрина каталога, интерактивный ретро-пейджер с цитатами, свежие поступления, статистика архива.
  - **Каталог книг**: рубрикатор, фильтрация по форматам, сортировка, карточки книг с обложками.
  - **Авторы**: алфавитный указатель (кириллица / латиница), карточки авторов, фильтр по эпохам.
  - **Хит-парад книг**: олимпийский пьедестал почёта топ-книг, табличный рейтинг читательских оценок с пагинацией, интерактивная шкала критериев и правила голосования, альтернативные чарты.
  - **Мои гости**: переходник на спецпроекты и партнерские сайты библиотеки.
  - **Сообщество**: система читательских достижений и интерактивный ламповый ретро-телевизор.
  - **О проекте**: манифест, хроника библиотеки с 1994 года, карточка создателя архива Максима Мошкова.
  - **Режим чтения (Reader)**: встроенная читалка с настройкой шрифта, сохранением закладок и переключением глав.
- **Адаптивность**: полная поддержка всех типов устройств — от десктопных мониторов до планшетов и смартфонов.
